# AURA Music PWA

移动端优先的 AURA Music Web 原型。照片、草稿和导出文件只在浏览器本地处理，服务端仅提供已发布模板和素材目录。

创作流程为“选择照片 → 填写音乐信息 → 一体化编辑器”。编辑器包含配方、排版、色块、播放器、文字和动态六类工具；可导出无水印静态 PNG，或在支持 H.264/MP4 录制的浏览器中本地生成 6 秒、30 FPS、无音频的动态 MP4。MP4 与 PNG 使用相同完整尺寸：1:1 为 1080×1080、3:4 为 1080×1440、9:16 为 1080×1920。旧草稿及远程目录中的 4:3 会在 PWA 内兼容迁移为 3:4。编码、分享和下载均不上传用户照片或作品。

播放器采用原创极简线条体系：悬浮信号线、唱片线、波形框、封面线、耳机线和心跳线。设计以细描边、留白、轻量等宽字和纵向音符动线为主，不打包参考图中的品牌、水印或装饰素材。

```bash
npm install
npm run dev
```

开发服务运行在 `http://localhost:5174`，并将 `/api` 代理到 `http://localhost:8080`。首次离线会使用内置 5 个模板。

```bash
npm test
npm run build
npm run preview
```

生产部署需要 HTTPS，构建产物位于 `dist/`。PWA 通过 Manifest 与 Service Worker 提供安装和离线应用壳；iPhone 需在 Safari 分享菜单中选择“添加到主屏幕”。
