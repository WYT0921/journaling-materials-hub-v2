# 自由拼贴技术设计

## 1. 功能定位

“自由拼贴”是一次性、纯前端图片编辑工具。用户选择平台内的单个手账素材，在 A6 或 A4 的横版/竖版画布中完成拖动、缩放、旋转、删除、复制和图层调整，最后导出高清图片到手机相册。

本期明确不包含：

- 本地或云端可编辑工程保存；
- 退出后恢复编辑；
- 跨设备同步；
- 作品列表、作品预览图和作品管理；
- 文字、画笔、滤镜、用户本地图片和透明背景。

编辑器退出后清空全部运行时状态；手机相册中的导出图片是唯一持久化结果。

## 2. 总体架构

前端新增独立自由拼贴模块，由以下部分组成：

- 编辑器页面：画布规格、素材选择、工具栏、图层面板、退出确认和导出反馈。
- 编辑器核心：维护画布、图层、选区和撤销/重做历史，不直接依赖 Vue 页面。
- 手势交互层：把单指拖动、双指缩放/旋转和控制点操作转换成图层变更。
- Canvas 渲染层：使用同一份场景数据完成屏幕预览和离屏高清导出。
- 素材加载层：调用现有素材接口，将远程图片下载为微信临时文件并管理加载状态。

后端继续提供现有素材查询、权限判断和文件访问能力。本期不新增作品表、作品接口、作品服务或服务端合成任务。

## 3. Canvas 与编辑器选型

使用微信小程序 Canvas 2D，并采用“屏幕 Canvas + 离屏导出 Canvas”双渲染模式：

- 屏幕 Canvas 按设备可视尺寸渲染，优先保证手势流畅度。
- 离屏 Canvas 按目标导出像素重新绘制，不能直接放大屏幕截图。

本期不引入 Fabric.js、Konva.js 等完整浏览器编辑库。它们依赖浏览器 Canvas、DOM 或浏览器事件模型，在微信小程序中的兼容层、包体和升级风险高于本期基础图片编辑需求。可按需使用无 DOM 依赖的小型数学工具，但运行时数据不能绑定第三方库的对象或序列化格式。

## 4. 画布规格

纸张和方向分别建模：

- `paperSize`: `A6 | A4`
- `orientation`: `portrait | landscape`

内部使用与屏幕无关的逻辑坐标：

- 竖版：`1000 × 1414`
- 横版：`1414 × 1000`

默认使用白色背景并导出高质量 JPEG。300 DPI 目标尺寸如下：

| 规格 | 竖版 | 横版 |
|---|---:|---:|
| A6 | 1240 × 1748 | 1748 × 1240 |
| A4 | 2480 × 3508 | 3508 × 2480 |

如果设备无法完成 A4 300 DPI 导出，明确提示用户改用 200 DPI 重试，不能静默降低分辨率。

## 5. 运行时场景模型

编辑期间维护结构化 Scene Graph，但不持久化为作品：

```text
editorState
  canvas
    paperSize
    orientation
    logicalWidth
    logicalHeight
    background
  layers[]
    id
    type
    materialId
    localImagePath
    sourceWidth
    sourceHeight
    x
    y
    baseWidth
    baseHeight
    scale
    rotation
    visible
    locked
    sourceKind
  selectedLayerId
  history
```

约束：

- `layers` 数组顺序就是从底到顶的绘制顺序。
- 坐标和基础尺寸使用逻辑坐标，显示与导出时分别换算。
- 图片默认锁定宽高比，允许部分移出画布，导出时裁剪到画布边界。
- 第一版最多 50 个图层。
- 页面销毁后释放 Scene Graph、历史栈、高清 Canvas 和临时对象，不写入 Storage、数据库或长期文件。

## 6. 编辑交互

- 单指拖动选中图层。
- 双指同时缩放和旋转。
- 选中框提供删除及旋转缩放控制点。
- 复制图层时生成新 ID，稍微偏移并置顶。
- 图层支持上移、下移、置顶、置底。
- 点击重叠区域默认命中最上层对象；图层面板用于确定性选择被遮挡对象。
- 命中检测采用旋转矩形逆变换，不做透明像素级命中。
- 添加、移动、缩放旋转、删除、复制和图层顺序均进入撤销/重做历史。
- 连续手势只在结束时形成一条历史记录。

存在未导出修改时退出页面，必须提示“退出后拼贴内容不会保留”。用户确认后立即清理状态。导出完成后可以停留在当前页面继续调整并再次导出，但退出后无法恢复。

## 7. 素材与权限

素材沿用现有后端能力：

1. 从单个素材详情页进入自由拼贴，或在编辑器素材选择器中选择素材。
2. 仅接受 `materialType=single` 的素材。
3. 按现有规则完成素材使用权限校验，不能使用模糊缩略图绕过会员或下载额度限制。
4. 使用 `uni.downloadFile` 将允许使用的原图下载到微信临时路径。
5. 素材完成加载后加入 Scene Graph；失败时保留其他布局并提供重试。

MinIO/Nginx 素材域名需要加入微信小程序合法下载域名。是否将“加入拼贴”记为一次下载，应与现有下载接口和免费额度规则保持一致，避免出现第二套权限口径。

## 8. 高清导出

导出流程：

1. 校验画布至少包含一个可见素材，且所有可见图层已成功加载。
2. 按纸张、方向和 DPI 计算目标像素。
3. 创建离屏 Canvas，按目标比例重放 Scene Graph。
4. 按图层数组顺序绘制图片并裁剪到画布范围。
5. 导出临时 JPEG 文件。
6. 请求相册权限并保存到手机相册。
7. 成功或失败后释放高清 Canvas 和临时对象。

异常处理：

- 相册权限被拒绝时引导用户打开设置。
- 导出期间锁定按钮，防止重复创建高清 Canvas。
- 素材加载失败时指出失败图层并禁止生成不完整图片。
- 300 DPI 因内存失败时提供 200 DPI 重试入口。
- Canvas 导出失败时释放资源并允许重试。

## 9. 模板与 AI 扩展

当前不保存用户工程，但编辑器必须保持通用 Scene Graph 边界，为后续能力复用：

- 模板是一份预设 Scene Graph，可包含背景、锁定图层和可替换素材槽位。
- 使用模板时将模板数据转换为当前运行时图层，编辑完成后仍只导出图片。
- AI 自动排版接收画布规格、素材 ID、宽高和标签，输出同一 Scene Graph 或可验证的布局指令，而不是直接输出图片。
- AI 结果进入现有编辑器后仍可手工调整，再由小程序 Canvas 导出。
- 只有未来重新提出“保存作品、继续编辑或跨设备同步”时，才新增作品持久化模块。

## 10. 验收标准

- A6/A4 与横竖四种组合的预览和导出比例正确。
- iOS、Android 微信真机上的拖动、双指缩放和旋转行为一致。
- 删除、复制、图层调整、撤销和重做结果正确。
- 屏幕预览与最终导出的图层位置、缩放、角度和顺序一致。
- 重叠图层可以通过图层面板选择。
- 30 至 50 个图层时仍可完成编辑和导出。
- A4 300 DPI 可正常导出；内存不足时能明确降级重试。
- 相册拒绝授权、素材加载失败和 Canvas 导出失败均有可恢复提示。
- 未导出退出时明确告知内容不会保留。
- 退出再进入编辑器时不会恢复上次工程。
- 用户不能通过自由拼贴获取无权限的素材原图。
