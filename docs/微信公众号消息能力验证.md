# 微信公众号图片与表情消息能力验证

## 能力边界

本模块只用于采集微信公众号明文消息回调及验证带 `MediaId` 消息的临时素材。它不包含用户绑定、正式表情仓库、AES安全模式或自动重试。

在真实测试完成前，不得声称微信收藏表情、系统黄脸或表情商店表情受支持。正式一期只应承诺公众号实际按可下载媒体消息推送的图片或GIF。

## 环境变量

| 变量 | 默认值 | 说明 |
|---|---:|---|
| `WECHAT_OFFICIAL_APP_ID` | 空 | 公众号AppID |
| `WECHAT_OFFICIAL_APP_SECRET` | 空 | 公众号AppSecret，禁止写入仓库 |
| `WECHAT_OFFICIAL_TOKEN` | 空 | 公众平台服务器配置Token |
| `WECHAT_OFFICIAL_PROBE_API_ENABLED` | `false` | 是否注册管理员查询接口 |
| `WECHAT_PROBE_MAX_FILE_SIZE` | `10485760` | 最大响应体字节数 |
| `WECHAT_PROBE_CONNECT_TIMEOUT_MS` | `5000` | HTTP连接超时 |
| `WECHAT_PROBE_READ_TIMEOUT_MS` | `15000` | HTTP请求超时 |
| `WECHAT_PROBE_MAX_REDIRECTS` | `3` | 最大重定向次数 |
| `WECHAT_PROBE_EXECUTOR_CORE_SIZE` | `2` | 异步线程池核心线程数 |
| `WECHAT_PROBE_EXECUTOR_MAX_SIZE` | `4` | 异步线程池最大线程数 |
| `WECHAT_PROBE_EXECUTOR_QUEUE_CAPACITY` | `100` | 有界任务队列容量 |

生产服务器的真实值只写入 `/root/journaling-materials-hub/deploy/.env`。部署包不得覆盖该文件。

## 微信公众平台配置

1. 部署公网HTTPS回调：`https://<域名>/api/wechat/official/callback`。
2. 在公众号后台“设置与开发 → 基本配置 → 服务器配置”填写该URL。
3. Token必须与 `WECHAT_OFFICIAL_TOKEN` 完全一致。
4. 消息加解密方式选择“明文模式”。
5. 提交时微信发送GET验证；成功响应为原始 `echostr`。
6. 设置 `WECHAT_OFFICIAL_PROBE_API_ENABLED=true` 并重新部署，用管理员登录接口取得JWT。

回调路径已从用户JWT拦截器排除，但会独立校验微信签名；管理查询仍经过JWT和管理员权限拦截。

## 本地调试与查询

```bash
cd backend
mvn spring-boot:run
```

dev Profile且探针API启用时，可用管理员JWT模拟XML解析和落库：

```http
POST /api/v2/admin/wechat-probe/simulate
Authorization: Bearer <admin-jwt>
Content-Type: application/xml

<xml>
  <ToUserName><![CDATA[to]]></ToUserName>
  <FromUserName><![CDATA[from-openid]]></FromUserName>
  <CreateTime>1785762000</CreateTime>
  <MsgType><![CDATA[text]]></MsgType>
  <Content><![CDATA[probe]]></Content>
  <MsgId>10001</MsgId>
</xml>
```

查询接口：

```http
GET /api/v2/admin/wechat-probe/messages?page=1&limit=20
GET /api/v2/admin/wechat-probe/messages/{id}
Authorization: Bearer <admin-jwt>
```

状态包括 `RECEIVED`、`DOWNLOADING`、`DOWNLOADED`、`FAILED`、`UNSUPPORTED`。列表不返回原始XML；详情中的OpenID和原始XML均脱敏。

## 真实公众号测试步骤

1. 确认回调和管理员查询均已启用，记录测试开始时间。
2. 逐项发送下表消息，每项只发送一次并等待状态稳定。
3. 用管理员接口核对回调字段和下载检测结果。
4. 对 `DOWNLOADED` 文件从MinIO下载，验证能否打开、GIF动画及SHA-256。
5. 重复推送测试中确认相同MsgId只有一条记录且文件只上传一次。
6. 超限测试可临时降低 `WECHAT_PROBE_MAX_FILE_SIZE` 后发送更大的图片。
7. 未收到回调或字段缺失必须如实填写，不得推断为支持。

## 已知限制

- 仅支持公众号明文模式。
- Redis故障时AccessToken降级为单实例进程内缓存。
- 没有自动后台重试；微信回调重推由数据库幂等键识别。
- WebP宽高取决于JVM ImageIO插件，无法读取不影响原文件保存。
- 验证文件位于现有公共Bucket，记录删除不保证旧URL失效。
- `PicUrl`存在但没有 `MediaId` 时不会通过PicUrl下载。
