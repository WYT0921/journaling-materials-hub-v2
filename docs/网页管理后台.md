\# 网页管理后台



\## Summary

\- 新建独立 Vue 网页管理后台，用于分类、素材、工具、用户和反馈管理，不放进小程序包。

\- 后端补齐管理 API 和数据结构，复用 `/api/v2/admin/\*\*` 管理端前缀。

\- 后台只保留一个管理员账号，使用账号密码登录；小程序用户不支持后台新增，只支持查看、禁用/启用、会员调整。



\## Key Changes

\- 后端管理登录：

&#x20; - 新增 `POST /api/v2/admin/auth/login`，通过 `ADMIN\_USERNAME` + BCrypt 密码哈希校验。

&#x20; - 管理员登录后返回 admin JWT，token 带 `role=admin`。

&#x20; - 管理端拦截器允许 admin JWT；保留现有 `admin.user-ids` 白名单兼容。

&#x20; - `.env.example` 增加 `ADMIN\_USERNAME`、`ADMIN\_PASSWORD\_HASH`、`ADMIN\_TOKEN\_EXPIRATION`。



\- 分类与工具数据：

&#x20; - 新增 `categories` 表：`id/name/type/status/sort\_order/created\_at/updated\_at`，`type` 为 `material` 或 `tool`。

&#x20; - 素材继续保留现有 `category` 字段，后台从分类表选择并保存分类名，避免破坏现有前台接口。

&#x20; - `tools` 表新增 `category` 字段；默认工具迁移/补种到数据库，前台工具列表从数据库读取 active 全局工具。

&#x20; - 管理 API：分类 CRUD、素材新增/编辑/上下架/删除/上传、工具新增/编辑/上下架/删除。



\- 用户与反馈管理：

&#x20; - 用户管理支持分页、搜索、状态筛选、启用/禁用、会员类型与到期时间调整。

&#x20; - 不提供新增小程序用户入口。

&#x20; - 反馈管理支持分页、状态筛选、查看详情、标记已处理/未处理、删除。



\- 独立后台前端：

&#x20; - 新建根目录 `admin-frontend/`，使用 Vue 3 + Vite，面向桌面浏览器。

&#x20; - 页面结构：登录页、后台主框架、分类管理、素材管理、工具管理、用户管理、反馈管理。

&#x20; - UI 采用高密度后台风格：左侧导航、顶部账号区、表格优先、抽屉/弹窗表单、清晰搜索筛选和状态标签。

&#x20; - 素材表单支持图片上传，调用现有 `/api/v2/admin/upload` 并自动填充图片与缩略图 URL。



\## Test Plan

\- 后端运行 `mvn test`，补充 Admin/Auth/Category/Tool/Feedback/User 管理接口测试。

\- 前端运行 `npm install` 后在 `admin-frontend` 执行构建验证。

\- 小程序端运行 `npm run build:mp-weixin`，确认新增后台不影响小程序包。

\- 手动验收：

&#x20; - 管理员账号可登录，错误密码被拒绝。

&#x20; - 分类可新增、编辑、禁用，并被素材/工具表单选择。

&#x20; - 素材可上传图片、新增、编辑、上下架。

&#x20; - 工具可按分类新增、编辑、上下架，前台工具页能看到启用工具。

&#x20; - 用户不可新增，但可搜索、禁用、修改会员状态。

&#x20; - 反馈可查看并标记处理。



\## Assumptions

\- 只需要一个网页后台管理员账号，不做多管理员/角色权限。

\- 管理后台作为独立 web 前端部署，不进入微信小程序页面。

\- 本次不重构小程序用户登录体系；后台 admin JWT 与小程序用户 JWT 并存。

\- 分类名称继续作为素材/工具的展示分类值，先不引入强外键，降低迁移风险。
